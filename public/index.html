🚀 How to Upload to GitHub & Deploy to Azure App Service

Follow these simple 4 steps to launch your app into production in the cloud.

1

Create GitHub Repository

Push this codebase to a new repository on GitHub:

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
2

Create Azure Web App

Go to Azure Portal and create a Web App:

  • Publish: Code
  • Runtime stack: Node 18 LTS or Node 20 LTS
  • Operating System: Linux or Windows
  • Pricing Plan: Free F1 or Basic B1
3

Get Publish Profile

Download the Azure Publish Profile:

  • In Azure Web App page, click Download publish profile.
  • In your GitHub Repo: Go to Settings > Secrets and variables > Actions.
  • Add a New Repository Secret named:
    AZURE_WEBAPP_PUBLISH_PROFILE
  • Paste the contents of the downloaded file.
4

Automated CI/CD Deployment

Your `.github/workflows/azure-deploy.yml` workflow is ready!

  • Update `AZURE_WEBAPP_NAME` in `.github/workflows/azure-deploy.yml` with your Azure app name.
  • Whenever you run git push, GitHub Actions will build and deploy automatically to Azure App Service!
